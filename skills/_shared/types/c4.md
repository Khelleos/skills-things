# c4

The system at one chosen level of zoom.

**Layout:** `container` — `payload` holds `nodes`, `edges` and `groups`.

**One type, four levels.** `meta.level` is 1, 2, 3 or 4, and the checker
requires it for this type and forbids it for every other. The layout and the
fields are the same at every level; only the grain changes.

| Level | One box is | The frame is |
|---|---|---|
| 1 context | a whole system | the world around it |
| 2 container | a deployable: an app, a service, a database | the system |
| 3 component | a major part inside one deployable | that deployable |
| 4 code | a class or a module | that component |

Pick the level from the reader's question, then draw **only** that level.
Mixing two levels on one page is the failure this type exists to prevent.

## Shows

At the chosen level: the boxes, what talks to what, and one frame marking
what is ours.

## Does not show

- Any other level. A level 2 diagram with one box opened up is two diagrams
  pretending to be one.
- Deployment. Where a container runs is `deployment`.
- Level 4, usually. Code-level C4 goes stale the day it is drawn; `class`
  answers the same question and is cheaper to redraw.

## Fields

`nodes[]`

| Field | Required | Notes |
|---|---|---|
| `id`, `label` | yes | |
| `role` | yes | `person`, `system`, `container`, `component`, `external`, `store` |
| `note` | no | the technology, at level 2: "Python, FastAPI" |

`groups[]` — usually exactly one, `kind: "system"`, holding everything inside
the boundary. People and external systems stay outside it.

`edges[]` carry the usual kinds, and every one should be labelled with what
crosses: `places an order`, not `calls`.

## Limits

9 nodes, 12 edges, 4 groups. C4's own guidance and the budget agree here for
once: a context diagram with more than nine boxes has stopped being a context
diagram.

## Reducing this type

- Go up a level. That is what levels are for, and it beats every other rung.
- External systems nobody in the room can change collapse into one box
  labelled for what they do.
- At level 2, a database used by exactly one container can be drawn inside it
  rather than beside it.

## When a table is better

At level 1, when there are no interesting relations — just a list of systems
and who owns them. Say so; a context diagram of six boxes and no arrows is a
list drawn expensively.
